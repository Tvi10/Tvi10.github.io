Wat is compressie?

Compressie betekent dat een bestand kleiner wordt gemaakt. Hierdoor neemt het minder opslagruimte in en kan het sneller worden verstuurd via internet.

Bitmap

Een bitmapafbeelding bestaat uit heel veel kleine pixels. Elke pixel bevat informatie over de kleur.

Foto's zijn meestal bitmapafbeeldingen. Wanneer je sterk inzoomt, kun je de afzonderlijke pixels zien.

Vector

Een vectorafbeelding wordt opgebouwd uit lijnen, vormen en wiskundige berekeningen.

Een voordeel is dat je een vectorafbeelding heel groot kunt maken zonder dat deze wazig wordt.

Bitmap tegenover vector

Bitmap

  • Bestaat uit pixels
  • Goed voor foto's
  • Kan wazig worden bij vergroten

Vector

  • Bestaat uit vormen en lijnen
  • Goed voor logo's
  • Kan zonder kwaliteitsverlies worden vergroot
